# Salary Role Comparator PWA

iPhone/iPad-friendly progressive web app for comparing salary packages.

## Included
- Basic salary
- Car allowance
- Employee pension %
- Mileage allowance + business miles
- Overnight allowance per night + editable number of nights/year
- Tax-free/taxable overnight toggle
- Hotel-paid-by-employer field
- Bonus
- Estimated annual/monthly take-home
- Monthly pension contribution and long-term projection
- Multiple saved roles stored only in localStorage
- Side-by-side comparison
- England/Wales/Northern Ireland and Scotland 2026/27 income-tax modes
- 2026/27 employee NI
- 2026/27 HMRC mileage approved amount (55p first 10,000 miles, 25p thereafter)

## Install
Upload all files to a GitHub Pages repository (root), enable Pages, open the HTTPS site in Safari,
then Share → Add to Home Screen.

The calculations are estimates and do not include every tax-code, benefit-in-kind or payroll scenario.
